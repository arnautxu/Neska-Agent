# Authorized server files

Server browsing and imported company knowledge are separate capabilities. Both require an installation-owned connection and explicit resource authorization. A connection label or natural-language request never grants access to a new root.

Use the generic document/server services and scoped reference contracts. Keep content hashes, provenance, size limits, private temporary storage, replay protection and permission rechecks. An unavailable adapter must report that condition; it must not imply that the company server is empty or that an old snapshot is live.

The repository provides mechanisms and fictional fixtures. Configure the adapter and perform two-user negative tests, revoked-access tests, transport interruption and document readback before enabling it. See [WINDOWS_DOCUMENT_SYNC.md](WINDOWS_DOCUMENT_SYNC.md).
