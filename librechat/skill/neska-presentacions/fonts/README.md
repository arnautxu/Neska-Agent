# Fonts for Neska slide decks

Latin and Latin Extended WOFF2 subsets from Fontsource (@fontsource/*@5), all under the SIL Open
Font License 1.1 (licence texts in this folder):

- Young Serif — The Young Serif Project Authors (`OFL-youngserif.txt`)
- Instrument Sans — The Instrument Sans Project Authors (`OFL-instrumentsans.txt`)
- Instrument Serif — The Instrument Serif Project Authors (`OFL-instrumentserif.txt`)
- Bricolage Grotesque — The Bricolage Grotesque Project Authors (`OFL-bricolagegrotesque.txt`)

They are embedded (subset) in the PDFs that `scripts/neska_pdf.py` writes, which the OFL allows.
`scripts/fonts.css` declares them.
